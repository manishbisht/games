# Prism implementation plan

Goal: Add a complete, original 3D shedding card game to the existing React game collection.

Architecture: A pure TypeScript command engine owns the entire round. AI consumes only its own hand and public information. Three.js renders table state and event animations; accessible React controls render the hand and dispatch validated commands.

Rules: 108 cards, seven per player, numbered opening discard, clockwise from seat one. Match color, number or action. Draw one; only that card can be played immediately. Penalties skip the recipient. Two-player reverse acts as skip. Draw Four requires no card of the active color. No stacking by default. Call Prism with two cards before playing, or with one before the next accepted play/draw. Another player can catch an uncalled player during that window for two cards. Final-card effects resolve before scoring. Recycle all but the top discard. An entirely exhausted, unplayable table ends in a draw without inventing cards.

- [x] Engine: define deck, models, centralized rules and immutable commands. Test legality, effects, draws, conservation, call windows, scoring, exhaustion and full simulated rounds.
- [x] AI: three levels using public knowledge only; verify chosen moves and completed 2–4-player rounds.
- [x] Presentation: original canvas/SVG artwork, real mesh cards and thick oval felt table, animated dealing/drawing/playing, responsive accessible hand, private local handoff, setup, help, settings and result dialogs, optional synthesized sound.
- [x] Integrate: add lazy route /prism, /uno alias and original collection preview without overwriting existing edits.
- [x] Verify: run unit tests, production build, lint and desktop/mobile browser tests including a complete round. Inspect rendered screenshots and correct issues.

Future extension boundaries: online transport can submit the same commands against an authoritative engine; custom-rule controls, jump-in, 7–0, music and tournament formats are outside this first milestone. Stacking and draw-until-playable are engine options; unsupported rules cannot be enabled silently.

Verification: 97 unit tests pass, including 15 Prism tests and 36 complete seeded round simulations. Production build and ESLint pass. Prism browser tests verify a complete round and replay, late calls after local handoff, desktop/mobile layouts, AI turns, settings and rules. Screenshots were inspected and lighting/mobile spacing refined. Independent review identified two call-control edge cases; both were reproduced by failing tests and fixed.
