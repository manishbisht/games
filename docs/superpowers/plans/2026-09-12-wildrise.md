# Wildrise implementation plan

**Goal:** Add a complete original 3D snakes-and-ladders game to the existing collection.

**Architecture:** A serializable, pure TypeScript reducer owns the board, rules, players, turn phases, movement and results. React schedules phase transitions and AI turns. Three.js renders state and interpolates movement without deciding game rules.

**Tech stack:** Existing React, TypeScript, Three.js, Vitest and Playwright dependencies; no backend changes or downloaded artwork.

**Design:** Wildrise is a woodland tabletop race. A pale tiled 100-space board has a walnut frame, brass ladders, sculpted colorful snakes, four animal miniatures and an ivory die. A warm cream interface contains the setup, compact player cards, current turn, event history and camera controls. Setup remains beside the real board so it is always the visual centerpiece.

## Tasks

- [x] Build and test `frontend/src/games/wildrise/game`: serpentine spaces, configurable routes/rules, fair dice, guarded phases, incremental movement, transport, exact finish, winner and serialization. Test complete seeded games with 2–4 players.
- [x] Build `frontend/src/games/wildrise/scene`: physical board, legible printed numbers, modeled animals, curved snakes, ladders, die, environment and camera. Dispose all scene resources on navigation.
- [x] Build `WildriseGame.tsx`, components and scoped CSS: local/AI setup, live status, players, turn control, events, sound, rules, pause, restart and victory. Pause timers on dialogs and hidden tabs. Respect reduced motion and keyboard/touch operation.
- [x] Register `/wildrise` and aliases, favicon and collection preview; retain existing games.
- [x] Verify engine unit tests, full frontend tests, TypeScript/build/lint and real-browser local/AI play through victory, mobile layout, camera, dialogs and navigation. Inspect screenshots.

Default rules: start off board at 0, exact 100, no bonus for six, shared squares, six configured snakes and six ladders. First player chosen uniformly. Optional AI styles affect timing/reactions only. Custom networking and a full custom-rule editor remain deferred as requested.
